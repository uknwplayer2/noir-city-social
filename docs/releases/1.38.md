# Noir City 1.38

> O APK foi compilado a partir da cópia local restaurada. A branch `initial-import` do GitHub ainda contém o código-base 1.0; a branch `release/1.38-record` guarda notas e regras, mas não o código e os sprites da build. Não use `initial-import` para reconstruir este APK. A árvore completa da 1.38 ainda precisa ser sincronizada com o GitHub para servir de backup durável do código.

## Mudanças

- A loja na barra inferior continua sendo o catálogo padrão. O botão de catálogo no topo só aparece para `admin` e abre os itens especiais, incluindo os móveis do Rooftop Night.
- Perfil salvo agora tem cargo `player`, `moderator` ou `admin`. O protótipo local mantém os perfis existentes como `admin` durante a migração para não retirar ferramentas de desenvolvimento.
- `:console` abre a Console Godmode para administradores, com concessão local de moedas e alerta visível no quarto.
- Pinça, roda e controles de zoom preservam o ponto de foco sob o gesto. Limites de escala: 0,65× a 2,4×.
- O painel inferior pode ser puxado para expandir, reduzir ou fechar com transição entre posições.
- Câmera captura o canvas do quarto, mostra prévia sem painel preto, e salva PNG em `Pictures/Noir City` na galeria do Android 10 ou posterior. Em versões anteriores, usa a pasta Pictures privada do app. A imagem capturada inclui a arte de fundo do quarto. O botão de publicação aparece desativado até a comunidade existir.

## Compatibilidade

- `versionName`: 1.38; `versionCode`: 39.
- Mesmo pacote Android: `com.patio.noir`.
- `SAVE_VERSION`: 3; migração aceita saves 1 e 2.
- Não foi alterada a chave de assinatura de debug usada nas compilações anteriores.
